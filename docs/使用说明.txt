这个软件是干什么的
────────────────────────────────────────────────────────────────

简单说：**它能让一枚"为别的相机做的"调色文件（LUT），变成"为你的相机做的"。**

打个比方 ——

    LUT 就像是给照片配的一副"眼镜"。
    戴上它，画面会变得好看（有特定的色调风格）。

    但是这副眼镜是照别人的眼睛配的。
    如果你的相机和那副眼镜不匹配，戴上去画面就是歪的。

    这个软件做的事，就是把这副眼镜"重新配一次度数"，
    让它适合你的相机。

例子：

    你下载了一枚很好看的 LUT，它是给 SONY 相机做的
    但你用的是 CANON 相机
    → 直接套上去，颜色是错的
    → 用这个软件转一下，就能用了


────────────────────────────────────────────────────────────────
                          重要的事情说在前面
────────────────────────────────────────────────────────────────

  ① 这个软件完全在你的电脑上运行，不上传任何东西，不需要联网。

  ② 它不需要安装什么"运行库"，也不需要管理员权限。

  ③ 想删掉它的时候，直接删文件夹就行，不会给电脑留下任何垃圾。

  ④ 整个压缩包解压后大约 170 MB，这是正常的（里面自带了一整套运行环境，
     所以你的电脑上不用装 Python 之类的东西）。

第 1 步 · 把整个文件夹拷到电脑里
────────────────────────────────────────────────────────────────

  先把这个文件夹**完整地**拷到你电脑上一个固定的位置，
  比如 [我的文档] 或者 D 盘。

  ⚠ 一定要拷**整个文件夹**，不能只拷里面某几个文件。
  ⚠ 不要直接在 U 盘里双击运行 —— 那样拔掉 U 盘就不能用了。

  建议放到这里：

      C:\Users\你的用户名\Documents\LUT跨色域转换

  （放在哪里都行，只要是个你不会随手删掉的地方）


第 2 步 · 双击「点我安装.bat」
────────────────────────────────────────────────────────────────

  在文件夹里找到这个文件：

      点我安装.bat

  用鼠标**双击**它。

  （如果你的电脑上看不到 ".bat" 这几个字，只显示"点我安装"，
    那也没关系，就是它。）

  会弹出一个黑色的窗口，里面滚出一段文字。

  **等它自己走完**，最后会显示「安装完成 ✔」和一行「按回车键关闭这个窗口」。

  这时候按一下键盘上的 **回车键**，黑窗口就关掉了。


第 3 步 · 回桌面看看
────────────────────────────────────────────────────────────────

  安装程序会自动在你的**桌面**上放一个图标。
  **它长这样：白底的圆角方块，中间一个三面不同颜色的彩色立方体
  （顶面偏蓝、左面偏青绿、右面偏洋红红），底下一条彩色小长条。**

      ┌────────────────────┐
      │   ◈  ← 彩色立方体    │
      │   LUT 跨色域转换    │
      └────────────────────┘

  看到它，就说明装好了。

  ⚠ 如果安装程序说「没能创建快捷方式」，那也没关系 ——
    你可以自己拖一个：
        · 在文件夹里找到  启动软件.bat
        · 用**右键**点住它，拖到桌面上，松手
        · 选「在当前位置创建快捷方式」


────────────────────────────────────────────────────────────────
                    如果安装时出现奇怪的提示
────────────────────────────────────────────────────────────────

  · 如果 Windows 弹出一个蓝色的窗口说「Windows 已保护你的电脑」
    → 点左边的「更多信息」，再点「仍要运行」。
      （这是因为软件没有花钱买数字签名，不是病毒。）

  · 如果弹出问「是否允许此应用对你的设备进行更改」
    → 通常不会弹。如果弹了，点「是」。

  · 如果黑窗口里出现看不懂的英文错误
    → 说明文件夹没拷全。把整个文件夹重新拷一遍再试。

第 1 步 · 双击桌面上的图标
────────────────────────────────────────────────────────────────

  双击桌面上的「LUT 跨色域转换」。

  会弹出一个**黑色窗口**，里面写着：

      ======================================================================
        LUT 跨色域转换
      ======================================================================

        正在启动，浏览器会自动打开。
        如果没打开，手动访问： http://127.0.0.1:8770

        数据目录（可安全删除）：C:\Users\...\AppData\Local\LUTConverter
        关闭本窗口即退出程序。
      ----------------------------------------------------------------------

  ⚠⚠ 这个黑窗口**不要关掉**！它就是软件本体。
      关了黑窗口，软件就退出了。

  等大约 2 秒，你的浏览器会**自动打开**一个网页，那就是软件的界面。

  如果浏览器没自动打开，就自己打开浏览器（Edge、Chrome 都行），
  在地址栏里输入黑窗口里显示的那个地址：

      http://127.0.0.1:8770

  然后按回车。


第 2 步 · 认识界面
────────────────────────────────────────────────────────────────

  界面长这样（见「图片说明」文件夹里的 overview.png）：

      ┌────────────────────────────────────────────┐
      │  1 · 载入                                   │
      │  ┌──────────────────────────────────────┐  │
      │  │   把 LUT 文件拖到这里，或点击选择      │  │
      │  └──────────────────────────────────────┘  │
      ├────────────────────────────────────────────┤
      │  2 · 文件里写了什么                         │
      │     （自动显示，不用管）                     │
      ├────────────────────────────────────────────┤
      │  3 · 这枚 LUT 现在吃 / 吐什么  ← 你要选这个  │
      │     输入：[ Sony S-Log3 / S-Gamut3.Cine ] │
      │     输出：[ Rec.709 display             ] │
      ├────────────────────────────────────────────┤
      │  4 · 换成                    ← 你要选这个   │
      │     输入端：[ Canon Log 3 / Cinema Gamut ] │
      │     输出端：[ Rec.709 display           ] │

  整个流程就是：**载入 → 告诉它现在是什么 → 告诉它你要换成什么 → 导出**

  想先练手：界面第 1 步下面有 5 个灰色小按钮
  （写着 "Sony S-Log3 → Rec.709" 之类），
  点一个，界面就会自动填好，不用你自己找文件。

「色彩空间」是什么
────────────────────────────────────────────────────────────────

  不用理解原理。你只要知道：**每个相机拍出来的素材，都有一个名字。**

      SONY 相机拍 → S-Log3
      CANON 相机拍 → Canon Log 3
      ARRI 相机拍 → LogC3 / LogC4
      尼康相机拍 → N-Log
      富士相机拍 → F-Log

  界面上的下拉列表里，这些名字都能选到。


第 3 步：告诉它「这枚 LUT 现在吃/吐什么」
────────────────────────────────────────────────────────────────

  这是最关键的一步。意思是：

      输入 = 这枚 LUT 原本是给什么相机做的？
      输出 = 它输出的是什么？（一般就是 Rec.709）

  ⚠ **软件不会帮你猜，需要你自己选。**

     为什么？因为 LUT 文件里**根本没有记录**这件事。
     它只存了一张"数字进、数字出"的对照表，不存这些数字是什么意思。

  那怎么知道该选什么？看这几个地方：

      ① **文件名**。比如 "SLog3SGamut3.CineToRec709.cube"
         → 一看就是 SONY 的 S-Log3 做的

      ② **下载它的页面**。商家会写"适用于 S-Log3"之类。

      ③ 界面第 2 步里有一栏「文件名/注释里出现了」，
         它会把文件名里认出来的字列出来给你参考。
         （这只是"抄"，不是"猜" —— 还是要你自己确认）

  确认好以后，在「输入」下拉框里选对应的那一个。


第 4 步：告诉它「我要换成什么」
────────────────────────────────────────────────────────────────

  「输入端」选**你自己的相机**拍出来的格式。

  举例 —— 你有一枚 SONY 的 LUT，但你用 CANON 拍：

      第 3 步  输入 = Sony S-Log3 / S-Gamut3.Cine    ← 这枚 LUT 本来是给 SONY 的
      第 3 步  输出 = Rec.709 display                ← 它输出普通显示器画面
      第 4 步  输入端 = Canon Log 3 / Cinema Gamut   ← 改成给 CANON 用
      第 4 步  输出端 = Rec.709 display              ← 输出不变

  「输出端」一般不用改。除非你也想让输出的画面变成 log 格式。

  选好之后，点绿色的 **[检查并导出]** 按钮。

点完「检查并导出」会看到什么
────────────────────────────────────────────────────────────────

  界面下方会出现一块报告（见 图片说明/step4.png）。
  你只需要看**两个**地方：

  ┌─────────────────────────────────────────────────────────┐
  │  自检：同空间还原                                        │
  │     最大误差   0.0e+00                                   │
  │     结论       ✓ 逐位精确                                │
  └─────────────────────────────────────────────────────────┘

  ⭐ **这里显示「逐位精确」= 一切正常，可以放心用。**

      如果这里显示「不精确」，那说明出问题了，
      把这次导出的文件删掉，换个色彩空间再试一次。


  ┌─────────────────────────────────────────────────────────┐
  │  输入端检查                                              │
  │     均匀采样越界   56.93%                                │
  └─────────────────────────────────────────────────────────┘

  ⚠ **这个百分比不用害怕，也基本可以忽略。**

      它测的是"把整个颜色空间切成均匀网格"时有多少格子越界。
      那些格子包括纯红、纯绿、满曝光的角点 ——
      **现实里不存在这种颜色。**

      实际测试：用真实照片里会出现的颜色（色卡、灰阶、各种色相）
      跑 13 家相机互相转换，**全部 0 损失**。

      只有当画面里有"特别亮 + 特别艳"的东西（过曝的霓虹灯、
      阳光直射的纯红色物体）时，那一小块会被压住。
      日常拍摄碰不到。


导出
────────────────────────────────────────────────────────────────

  报告上方有一个 **[下载]** 按钮，点它就下载了。

  三种格式选哪个：

      .cube   ← 90% 的情况选这个。达芬奇、Premiere、FCP 都能用
      .3dl    ← Autodesk Lustre / Baselight 这类专业调色系统用
      .vlt    ← Panasonic 相机机内监看用（固定 17³）

  网格选哪个：

      33³   ← 默认，够用
      65³   ← 更细腻，文件大 7 倍，特殊素材才需要
      17³   ← 最省，只在相机机内用


用完怎么关
────────────────────────────────────────────────────────────────

  直接关掉那个**黑色窗口**就退出了。
  浏览器里的页面可以留着，下次打开软件还是这个地址。

问：双击了图标，什么都没发生？
答：可能黑窗口一闪就关了。试试用**右键**点图标 → 「以管理员身份运行」。
    如果还不行，直接进文件夹双击 启动软件.bat，
    这样黑窗口会留着，能看到错误信息。


问：黑窗口关了以后，浏览器里的页面打不开了？
答：正常。黑窗口就是软件本体，关了就等于退出。
    重新双击桌面图标就行。


问：浏览器没有自动打开？
答：自己打开浏览器，地址栏输入黑窗口里显示的那个地址
    （一般是 http://127.0.0.1:8770 ），按回车。


问：窗口里说端口被占用？
答：说明你已经开着一个了。看看任务栏有没有另一个黑窗口，
    关掉再开。软件会自动换端口，所以其实不影响。


问：拖进 LUT 文件，提示读取失败？
答：可能是不支持的格式。目前支持：
      .cube  .csp  .spi1d  .spi3d  .spimtx  .3dl  .vlt
    如果你的是 .dat 或 .ilut，暂时不支持。


问：下拉列表里找不到我的相机？
答：列表里有 13 家厂商 29 个色彩空间：
    SONY、CANON、NIKON、FUJIFILM、PANASONIC、ARRI、RED、
    DJI、BLACKMAGIC、DAVINCI、APPLE、FILMLIGHT、GOPRO
    如果确实没有，那这个版本还不支持。


问：转换出来的 LUT 用上去颜色还是不对？
答：八成是第 3 步的「输入」选错了。
    那一步是整个流程里唯一需要你判断的地方，
    再核对一下 LUT 原本是给什么相机做的。


问：这个软件有病毒吗？为什么杀毒软件报警？
答：没有病毒，全程不联网。报警是因为没有购买数字签名证书
    （那要每年几千块钱）。点「仍要运行」即可。
    你也可以直接打开 app 文件夹看，全是文本代码。


问：为什么文件夹这么大（170 MB）？
答：因为里面自带了一整套 Python 运行环境。
    好处是你的电脑上**不需要预装任何东西**，拷过去就能用。
    代价就是体积大一点。


问：怎么彻底删掉？
答：按 Win+R，粘贴这一行，回车：

      %LOCALAPPDATA%

    然后删掉里面这两个文件夹：
      · Programs\LUTConverter    （程序本体，装在这里，没占多少地方）
      · LUTConverter             （临时文件，只有你导出时的中转文件）

    最后删掉桌面上的快捷方式。

    就完了。不会有任何残留，也不影响系统。
    （其实只删桌面图标也够用，剩下那点文件不占地方。）


问：这个软件会不会把我电脑里的东西传出去？
答：不会。它只在你自己电脑上算，连网络都不用。
    信不过的话，可以把网线拔掉再用，功能一样。


────────────────────────────────────────────────────────────────
                          技术信息（可以不看）
────────────────────────────────────────────────────────────────

  · 色彩管线以 ACES2065-1 为枢纽，任意两个空间之间互通
  · 色彩空间定义来自公开规范，配合 colour-science 0.4.7、
    OpenColorIO 2.6.0
  · .3dl 的网格顺序经 OpenColorIO 独立比对验证，偏差 1.22e-4
    （半个 12 位码值，即纯量化误差）
  · .vlt 读→写→读完全精确（误差 0.0）
  · 同空间重定向还原精度：0.0
  · 软件**不含任何厂商 LUT 文件**，也不分发。它只是把你手上
    已有的 LUT 重新接线。

  界面里有「自检」按钮，可以随时自己验证上面的数字。
